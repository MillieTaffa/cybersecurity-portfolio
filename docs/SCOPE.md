# Scope

## In scope

- phishing URL analysis
- SQL injection exposure checks in a controlled lab
- small configuration checks
- severity and confidence scoring
- finding storage and reporting
- dashboard display
- remediation verification

## Out of scope

- XSS testing
- CSRF testing
- dependency vulnerability scanning
- cloud configuration scanning
- brute-force testing
- credential attacks
- full security exploitation frameworks

## Safety rule

All testing must be explicit and authorised.

This project is designed for learning, demonstration, and controlled local security testing only.
